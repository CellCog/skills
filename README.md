# CellCog Skills

[![skills.sh](https://skills.sh/b/cellcog/skills)](https://skills.sh/cellcog/skills)

Official agent skills for [CellCog](https://cellcog.ai) — delegate deep research, image, video, audio and music generation, documents, spreadsheets, dashboards, 3D models, diagrams, and more to CellCog from any coding agent. One request in, finished deliverables out.

CellCog is #1 on [DeepResearch Bench](https://huggingface.co/spaces/muset-ai/DeepResearch-Bench-Leaderboard) (July 2026) — deep reasoning paired with every output modality.

## Install

```bash
# Recommended start: the core skill + the modality you need
npx skills add cellcog/skills --skill cellcog --skill deep-research-cellcog

# Or grab the whole fleet
npx skills add cellcog/skills --all
```

Works with Claude Code, Cursor, Codex, OpenCode, Gemini CLI and 70+ more agents.

**OpenClaw users:** these skills are also published on [ClawHub](https://clawhub.ai/cellcog) — `clawhub install cellcog`.

## Setup

The skills call CellCog through the Python SDK:

```bash
pip install -U cellcog
export CELLCOG_API_KEY=...   # get a key at https://cellcog.ai
```

Start with the **cellcog** skill — it carries the full SDK reference (file handling, chat modes, timeouts).
